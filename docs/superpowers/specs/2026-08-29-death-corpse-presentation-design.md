# 死亡尸体平面表现设计

日期：2026-08-29
状态：已获用户确认

## 目标

让死亡的干员、地面小兵与空中小兵不再保留直立单位模型，而是在原位置留下与阵营颜色一致的平面尸体。空中小兵的尸体需要有短暂下落动画。尸体必须是独立对象，以便未来单独加入体积碰撞、阻挡规则和生命周期管理。

## 范围

包含：

- 玩家干员；
- 地面小兵；
- 空中小兵。

不包含：

- 防御塔与训练目标；
- 尸体阻挡、物理碰撞、尸体消失/回收和对象池；
- 攻击、选中、移动或胜负规则的改动。

## 设计

### 活单位与尸体的边界

新增一个只处理死亡外观的组件，并只在本次范围内的活单位上配置。它订阅 `CombatUnit.Died`，每个单位只响应一次：

1. 读取单位的位置、阵营材质与高度类别；
2. 创建一个独立的平面尸体对象；
3. 立即隐藏原单位渲染，再按 Unity 的正常生命周期销毁原单位对象；
4. 尸体不添加 `CombatUnit`，不使用 `Targetable` 层，也不保留活单位的移动、攻击或输入组件。

这使尸体与活单位完全分离。未来的尸体碰撞体、阻挡层或消失时间只加入尸体对象，不会影响寻敌、攻击指令或活单位碰撞。

### 外观与落地

尸体统一使用水平平面，大小与现有胶囊体视觉近似，并使用生成单位时已知的蓝/红共享材质，不创建新的阵营颜色材质。

- 地面单位：尸体直接放在脚下的地面上方一个很小的偏移处，避免与地面闪烁。
- 空中小兵：尸体先出现在死亡的空中位置，再在 **0.3 秒** 内线性落到同一 X/Z 位置的地面上方小偏移处，落地后停止。

落点优先通过向下检测场地地面取得；原型场地中未命中时以 `Y = 0` 的地面高度作为回退，保证动画不会悬空。

尸体平面当前没有碰撞体，且不阻挡鼠标或单位。它是以后增加独立体积碰撞的承载点，而不是当前碰撞规则的一部分。

### 场景接入

`PrototypeSceneBuilder` 为玩家干员配置死亡尸体组件并传入蓝方材质。`MinionWaveSpawner` 为每一个地面/空中小兵配置同一组件并传入该兵种所属的阵营材质和高度类别。塔与训练目标不配置该组件。

## 测试与验收

新增可自动回归的测试，验证：

1. 地面单位死亡后生成同色平面尸体，原单位不再保留为活单位；
2. 空中小兵的尸体从死亡高度开始，在 0.3 秒后停在地面；
3. 尸体不含 `CombatUnit`、不在 `Targetable` 层，因而不能作为攻击或命令目标；
4. 塔和训练目标死亡时不生成尸体。

人工验收：在原型场景中击杀地面小兵、空中小兵与干员。确认地面尸体即时贴地、空中尸体可见下落、原单位不再直立显示，且塔和训练目标保持原表现。

## 风险与后续

当前尸体会保留在场景中；这符合原型可观察性目标，但长局会积累对象。对象池、消失时间、尸体阻挡与碰撞分层留待后续阶段，且不会改变本设计的活单位/尸体边界。
