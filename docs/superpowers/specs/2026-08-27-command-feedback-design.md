# 指令反馈设计

## 目标

为阶段 3 的移动与攻击原型提供可观察的操作反馈：鼠标悬停到合法攻击目标时显示圆形准星；仅在按住 `Q` 期间显示玩家真实攻击范围的世界空间圆环，并将松开 `Q` 视为取消攻击待命。

## 范围

本次实现：

- 合法目标悬停反馈；
- Q 按住期间的攻击范围圆环；
- Q 松开取消待命状态；
- 覆盖上述行为的播放模式回归测试。

本次不实现：HUD、血条、选中框、多单位选择、技能范围、可配置按键 UI、塔的攻击行为或任何新目标规则。

## 交互规则

### 悬停准星

玩家鼠标下的对象只有同时满足以下条件时，才显示黄色圆形准星：

1. 射线首先命中 `Targetable` 层对象；
2. 命中的对象挂有 `CombatUnit`；
3. `TargetRules.IsLegal(player, target)` 返回真。

否则恢复默认系统指针。目标是否在当前攻击距离内不影响悬停准星：合法的远距离目标可被直接攻击并触发追击。死亡、友方、塔或其他没有 `CombatUnit` 的 `Targetable` 对象不会显示准星。

### Q 攻击范围

`Q` 是按住态，而不是切换态：

- 按下 Q：进入攻击待命，并显示范围圆环；
- 保持 Q：圆环以 `Player_Exusiai` 脚下为圆心，半径严格等于其 `CombatUnit.AttackRange`；
- 按住 Q 左键：若鼠标下为合法可选目标，发出 `Attack(target)`；否则发出 `AttackNearestInRange`；
- 松开 Q：立即取消待命并隐藏圆环；
- 右键或 Esc：同样取消待命并隐藏圆环。

这不改变既有攻击意图：Q+左键地面、墙体或空白处只尝试攻击当前范围内最近的合法目标，绝不前往点击位置。

## 架构

新增玩家组件 `CommandFeedbackPresenter`：

- 依赖同一对象的 `CombatUnit` 和 `PlayerCommandController`；
- 在 `Update` 中读取控制器的 Q 按住状态，维护一个运行时 `LineRenderer` 圆环；
- 使用与输入一致的主相机和指针位置射线；通过 `TargetRules.IsLegal` 判定悬停合法性；
- 使用运行时生成且缓存的黄色圆形光标纹理，并在对象销毁时恢复默认光标和释放该组件拥有的资源。

`PlayerCommandController` 公开只读 `IsAttackMoveHeld`，并订阅 `AttackMove.canceled`；取消路径统一清除待命状态。为避免两处射线规则偏离，控制器提供读取当前鼠标射线命中结果的只读方法，反馈组件复用它。

## 测试

播放模式测试覆盖：

- Q 按下时待命和范围环可见，Q 松开时二者均被取消；
- 范围环半径与实际 `AttackRange` 一致；
- 合法红方目标悬停状态为真；友方、死亡、无 `CombatUnit` 的 Targetable 对象状态为假；
- 现有右键与 Q+左键输入测试继续覆盖命令语义。

测试不依赖操作系统真实光标位图，而是断言 `CommandFeedbackPresenter` 的可观察悬停与范围可见状态；该状态是光标和圆环渲染的唯一输入。

## 人工验收

进入 Play Mode 后：

1. 鼠标悬停红色训练假人，指针变为黄色圆形准星；移到红塔、蓝方物体或地面时恢复默认。
2. 按住 Q，玩家脚下显示黄色攻击范围圆环；松开 Q，圆环立即消失。
3. 按住 Q 点击红色训练假人，玩家追击并攻击。
4. 按住 Q 点击地面、墙体或空白处，玩家不前往点击位置；若范围内有合法目标则攻击最近者。
