# 干员体型与单位血条设计

日期：2026-08-30  
状态：已获用户确认

## 目标

让玩家干员在原型战场中具有比小兵更醒目的体积，并为玩家干员与自动生成的地面、空中小兵提供始终可见的头顶血条，便于区分单位身份和观察战斗结果。

## 范围

包含：

- 放大 `Player_Exusiai` 的现有胶囊体视觉与碰撞体；
- 为玩家干员、地面小兵与空中小兵显示世界空间血条；
- 根据 `CombatUnit.CurrentHealth / MaxHealth` 实时更新血条填充；
- 在角色死亡、被尸体表现组件销毁时一并清除血条。

不包含：

- 修改干员或小兵的攻击属性、攻击距离、移动速度、寻敌和胜负规则；
- 为防御塔、训练目标或尸体添加血条；
- 血条隐藏延迟、受伤动画、数值文字、护盾、治疗或对象池；
- 修改用户已经手动保存的场景与项目设置。

## 设计

### 干员体型

保留当前的胶囊体，而不更换为新模型。场景构建器将玩家干员的 X/Z 直径和 Y 高度同时放大，使其明显大于保持现有尺寸的小兵；胶囊自身的碰撞体随 Transform 缩放，因此视觉与可碰撞体积保持一致。

放大只改变场景表现和碰撞体积。干员的 `CombatUnit` 数值与 `UnitMotor` 配置保持不变。创建时同步提高胶囊的 Y 位置，确保其底部仍贴在地面上，而不是嵌入地面或悬空。

### 血条表现

新增独立的 `HealthBarPresenter` 组件，负责单个活单位的头顶血条。它读取同一对象上的 `CombatUnit`，在运行时创建一个作为单位子物体的世界空间 Canvas：

- 深色背景条表示最大生命；
- 前景使用绿色填充条表示当前生命比例；
- 前景宽度由 `CurrentHealth / MaxHealth` 决定，并被限制在 0 到 1；
- 血条持续显示，不因满血、未选中或未受伤而隐藏；
- 每帧根据单位渲染边界将血条放在头顶上方，并让它朝向主相机，保持可读；
- 空中小兵的血条随其当前位置移动，不在地面预先显示。

血条是单位对象的子物体，因此 `DeathCorpsePresenter` 销毁活单位时，血条会随之销毁；尸体平面没有血条，也不会成为血条的父级。

### 场景接入

`PrototypeSceneBuilder` 在创建 `Player_Exusiai` 时设置更大的胶囊 Transform，并挂载 `HealthBarPresenter`。

`MinionWaveSpawner` 在创建每个地面和空中小兵时挂载同一组件。生成波次后，所有存活小兵和玩家干员的血条均始终可见。

组件独立于场景预制配置：它在 `Awake` 中获取 `CombatUnit` 并自行创建视觉子物体，避免向场景文件或手动设置对象序列化 UI 引用。

## 测试与验收

自动化测试覆盖：

1. 血条创建后，初始填充为 100%，并且满血时仍处于显示状态；
2. 单位受到伤害后，血条填充与生命比例同步；
3. 血量归零时，血条所属对象随活单位销毁，不附着在尸体平面上；
4. 原型场景构建器创建的玩家干员具有比地面小兵更大的碰撞体积，并包含血条组件；
5. 小兵波次中的地面与空中小兵均包含血条组件。

人工验收：重新构建 Prototype Arena 并运行场景。确认蓝方干员比胶囊小兵醒目，所有活干员和小兵头顶都持续显示血条；攻击任意单位后对应绿条缩短；单位死亡成为平面尸体后，血条消失。

## 风险与后续

本阶段的世界空间 Canvas 数量与存活单位数线性增长，适合当前原型的小规模波次。若以后增加大量单位，应改为共享血条 Canvas 或对象池；这些优化不改变 `HealthBarPresenter` 的生命数据边界。
