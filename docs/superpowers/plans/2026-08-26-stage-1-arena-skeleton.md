# 阶段 1：战场骨架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 macOS 上建立 Unity 6.3 URP 灰盒工程，并交付可在 Editor 中运行、可导航的对称单路战场。

**Architecture:** 运行时程序集只提供稳定枚举、场地布局、启动校验与相机控制。编辑器脚本确定性地配置 URP 并生成唯一的 `PrototypeArena` 场景，避免手工场景漂移。先以 EditMode 覆盖纯布局规则，再以 PlayMode 验证场景根对象和相机。

**Tech Stack:** Unity 6000.3.15f1、C#、URP 17.3.0、Input System 1.17.0、Unity Test Framework、NUnit、macOS。

## Global Constraints

- 首版仅验收 macOS、1920×1080、60 FPS；使用离线 3D 灰盒表现。
- 运行时代码位于 `Assets/Game/Scripts`，测试位于 `Assets/Tests`；不提交 `.DS_Store`、`Library/`、`Temp/`、`Logs/`、`Obj/`、`Builds/` 或 `TestResults/`。
- 地图是一条对称单路：蓝/红塔在 `(-38,0,0)` 与 `(38,0,0)`，部署区在 `(-46,0,0)` 与 `(46,0,0)`，可活动边界为 X `[-50,50]`、Z `[-12,12]`。
- 不实现联网、角色战斗、兵线、HUD、AI、技能或正式资源；此阶段仅提供场地骨架、塔占位物和相机。
- Unity Input System 是项目后续唯一的输入入口；本阶段相机只使用 Input System，禁止 `UnityEngine.Input`。

```csharp
using NUnit.Framework;
using UnityEngine;

namespace ArknightsFrontline.Tests.EditMode;

public sealed class ArenaLayoutTests
{
    [Test]
    public void DefaultLayoutMirrorsTowersAndDeploymentZones()
    {
        ArenaLayout layout = ArenaLayout.CreateDefault();
        Assert.That(layout.BlueTower, Is.EqualTo(-layout.RedTower));
        Assert.That(layout.BlueDeployment, Is.EqualTo(-layout.RedDeployment));
        Assert.That(layout.LaneHalfLength, Is.EqualTo(50f));
        Assert.That(layout.LaneHalfWidth, Is.EqualTo(12f));
    }

    [Test]
    public void ClampToArenaKeepsPointInsideBounds()
    {
        ArenaLayout layout = ArenaLayout.CreateDefault();
        Assert.That(layout.Clamp(new Vector3(90f, 0f, 30f)), Is.EqualTo(new Vector3(50f, 0f, 12f)));
    }
}
```

- [ ] **Step 3: Implement layout, camera and deterministic scene construction**

`ArenaLayout.CreateDefault()` returns the positions and bounds in Global Constraints; `Clamp` uses `Mathf.Clamp` on X/Z and returns Y `0`. `ArenaBootstrap` exposes assigned blue and red tower transforms and rejects missing references with clear object/field names.

`MobaCameraController` uses Input System actions; it has a 20-pixel edge threshold, movement speed `18` world units/second, middle-button drag at `0.03` world units per screen pixel, and clamps its focus through `ArenaLayout`. `CenterOn(Transform)` clamps the target position before moving focus.

`PrototypeSceneBuilder.Build()` creates and saves `Assets/Game/Scenes/PrototypeArena.unity` containing exactly one `ArenaBootstrap` root, a `100×24` plane named `Lane`, blue/red cubes at tower positions, blue/red deployment markers, a directional light, a perspective main camera at `(0,35,-28)` with rotation `(50,0,0)` and `MobaCameraController`, plus an EventSystem and Canvas.
