# 银灰

**分支：**近卫/领主

**所属势力：**谢拉格

## 特性

**领主：**有远近2个攻击范围，根据技能效果可以进行远程攻击，但此时攻击力降低至**80%**

> 近程攻击：攻击范围小，不可攻击空中单位，造成范围伤害
>
> 远程攻击：攻击范围大，可以攻击空中单位，造成单体伤害；远程攻击近程范围内的地面敌人时，仍判定为近程攻击
